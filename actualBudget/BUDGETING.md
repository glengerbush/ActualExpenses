# Monthly tracking and envelope budgets

Tickets17/18; spec stories33–40. Reference: immutable Actual26.10.0, commit2bebdbaae0b701120a8cad9d56aafd64fa04c577, `packages/loot-core/src/server/budget/{base,tracking,envelope,actions}.ts`.

`budgeting` owns monthly calculations, allocation actions and source conversion. Ledger leaf rows remain actuals authority. No spreadsheet cache or browser optimistic total becomes financial authority. Integer minor units accumulate in i128 and must remain within the existing exact-money range; an overflowing action rolls back in full.

Schema16 retains both `reflect_budgets` and `zero_budgets` domains as scoped `budget_cells`, monthly holds/notes as `budget_months`, and the active method as `budget_settings`. Source goal metadata is retained. Method changes preserve the inactive allocation domain. Native archives/duplicates include all three domains; the existing private history exclusion and epoch rotation still apply. Old imports are enriched from retained original records; ready old stages are reinspected. No source version is fabricated.

Tracking carries signed category leftovers only when the preceding month enables carryover. Income remaining is planned minus actual; expense remaining is planned plus signed actual. Projected savings use planned income minus planned expense; final savings use actual income plus signed expense. Tracking excludes hidden categories from totals and hidden expense groups from summaries.

Envelope always carries positive category balances. Negative balances carry only when flagged; otherwise they reduce the following month's available funds once. A nonzero manual hold overrides automatic held income categories; manual zero releases that override. Holds accept a clamped delta. Refunds retain their sign. Actuals and drilldown use the same live on-budget leaf predicate, including categorized off-budget transfer crossings and opening debt; parent transactions cannot double count.

`GET /api/v1/budgets/{budget}/budget?month=YYYY-MM&count=1..12` returns confirmed months, summary, categories, snapshot, epoch and edit clock. `POST` applies one action: set/carryover, copy previous/year, zero, hold/reset, move/cover, month/category notes, method. `GET .../budget/transactions` pages contributing ledger rows at one snapshot. OpenAPI describes fields and headers. Month values are canonical ASCII YYYY-MM. Carryover applies through the current planning horizon; copy-year stops at December and that horizon. Copy previous excludes hidden categories/groups and envelope income, copying amounts alone.

Each action is one atomic receipt and optional owner history group. Original key/body/owner/epoch/clock survive retry; exact receipts precede current snapshot/epoch checks. Lookup cannot execute unknown work. Cancellation records a terminal outcome before changes. Affected fields with an equal or newer clock refuse the entire action, including composite copies and moves. Category merge transfers active-method expense allocations and retains retired cells; allocation versions and existing reference guards protect undo. Change cursors serialize all planning entities; native clients can advance past them without losing expense changes.

The Budget pane keeps durable local drafts. It captures number format, owner, epoch and original intent clock before dispatch; refresh does not replace pending identity. Storage failure or cross-tab draft changes block sending. Lost acknowledgements retain the original request for unchanged retry or safe cancellation. Restored epochs require explicit review of retained fields. Offline edits retain local fields and confirmed figures.
