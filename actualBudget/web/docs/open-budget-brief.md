# Open budget surface

Task: create or select a persistent budget and account, enter exact opening balance/date, revisit it after restart. Inputs: name, account name/type, opening balance/date and notes. Empty state explains how to begin; loading announces work; failures retain values and offer retry. Confirmation uses real server balances. Keyboard flow follows reading order. Mobile navigation stacks above content.

Visual choices are delegated implementation assumptions, not new product requirements. Operate code-first; system sans, quiet light workspace, green active/action states, compact account navigation. No decorative assets needed. No login/offline engine or placeholder future features.
