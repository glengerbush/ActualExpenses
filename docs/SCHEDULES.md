No replacement code or rewritten expected calculations enter the oracle.

Generated IDs are normalized by first appearance after sorting same-date UUID-only ties by schedule/account/amount/notes. Values, dates, references and financial multiplicity remain exact. These snapshots do not assert a meaningful ordering between otherwise unrelated same-date transactions; dedicated ledger-order checks remain separate.
