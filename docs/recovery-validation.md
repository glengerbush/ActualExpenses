## Safety boundaries

Strict native restore validation remains mandatory. Structurally invalid graphs/references are preserved and reported, not repaired under a backup that normal restore would reject. This slice supplies no permissive restore mode, raw server DB swap, synthetic transfer partner, orphan-purchase deletion, history/receipt expiry, epoch reset or client-clock rewrite. Repairs leave the current epoch intact; actual backup restore retains existing epoch rotation/monotonic receipt rules. Downloaded-cache reset allowlists rebuildable keys; unknown entries, lifecycle/repair operations, staged originals, other databases and all outboxes remain intact. Display-preference caches may be removed, never device settings/drafts. Privacy masking is retained; unknown display preferences mask financial comparisons and require reconnect before a new approval. Native cold-offline app loading remains outside the limited-offline boundary; interrupted browser tests keep static code reachable while API requests fail.
